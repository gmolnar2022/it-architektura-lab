2. hét – Azure VM menedzsment és PowerShell

Skillable → VS Code → Azure PowerShell → RDP → Windows PowerShell → Pipeline → Script

A második heti gyakorlaton először egy Microsoft Skillable labor segítségével ismételjük át az Azure virtuális gép létrehozását. Ezután Visual Studio Code-ból használjuk az Azure PowerShell parancsokat, majd RDP-vel belépünk a virtuális gépre, és ott Windows PowerShell parancsokkal vizsgáljuk meg a gép erőforrásait. A gyakorlat végén pipeline-t, változókat és egy egyszerű PowerShell scriptet használunk.

ImportantHogyan használd?

A feladatokat sorrendben végezd el. A válaszmezők tartalmát a böngésző ezen a gépen automatikusan megőrzi.

A gyakorlat végén add meg a Neptun-kódodat, majd válaszd a Beadás gombot. Jelszót, Training Key-t vagy más hitelesítési adatot ne írj a munkafüzetbe.

A Neptun-kód 6 betűből és/vagy számjegyből áll.

I. Ismétlés – Skillable és Azure VM

1. feladat – Regisztráció a Skillable rendszerbe

Nyisd meg a Skillable / Microsoft Learn for Educators laboroldalt: https://msle.learnondemand.net/.

  1. Válaszd a Register with Training Key lehetőséget.
  2. Add meg az oktatótól kapott Training Key értéket, majd válaszd a Register gombot.
  3. Töltsd ki a regisztrációhoz szükséges adatokat, és hozd létre a fiókodat.
  4. A regisztráció után jelentkezz be a Skillable rendszerbe.
WarningFontos

A Training Key-t, a jelszavadat és más belépési adatot ne írd be ebbe a munkafüzetbe. Jegyezd meg a Skillable felhasználónevedet és jelszavadat, mert később is szükséged lehet rájuk.

2. feladat – A labor megkeresése

Bejelentkezés után nyisd meg a Current Training részt, majd válaszd ki az oktató által megadott kurzust. Ha a rendszer kéri, végezd el a Get Ready / Software Check lépést és fogadd el a Microsoft End User License Agreementet.

Keresd meg az elérhető laborok között a Deploy an Azure Virtual Machine [Guided] labort.

3. feladat – Deploy an Azure Virtual Machine [Guided]

Indítsd el a Deploy an Azure Virtual Machine [Guided] labort, és végezd el a labor utasításait. A végrehajtás közben figyeld meg különösen az Azure VM legfontosabb beállításait: Region, Image, Size, Disks, Networking.

II. Azure menedzsment Visual Studio Code-ból

4. feladat – Visual Studio Code előkészítése

Indítsd el a Visual Studio Code alkalmazást a tantermi gépen.

  1. Nyisd meg az Extensions nézetet (Ctrl+Shift+X).
  2. Keresd meg az Azure Resources bővítményt.
  3. Ha nincs telepítve, telepítsd.
  4. Nyisd meg az Azure nézetet a VS Code bal oldali sávjában.
  5. Jelentkezz be az Azure-ba az egyetemi Microsoft-fiókoddal.
  6. Ellenőrizd, hogy az Azure-előfizetésed megjelenik-e a Resources nézetben.

NoteHa az Azure Resources nincs telepítve

Telepítsd az Azure Resources bővítményt a VS Code Extensions nézetéből, majd jelentkezz be újra.

5. feladat – Azure bejelentkezés és előfizetés

Nyiss egy PowerShell terminált a VS Code-ban, majd a korábban tanult Azure PowerShell parancsok segítségével:

  1. jelentkezz be az Azure-ba;
  2. listázd az elérhető előfizetéseidet;
  3. ha több előfizetésed van, válaszd ki azt, amelyet a gyakorlaton használsz.
NoteHa a Powershell parancsot nem fogadja el

Add ki egymás után a következő parancsokat:
Install-Module -Name Az -Scope CurrentUser -Repository PSGallery -Force -AllowClobber
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Connect-AzAccount

6. feladat – Egy erőforráscsoport lekérdezése

A korábban tanult Azure PowerShell parancs segítségével kérdezd le azt az erőforráscsoportot, amelyben a saját virtuális géped található.

A lekérdezésben paraméterként add meg az erőforráscsoport nevét. A kimenet alapján add meg az erőforráscsoport helyét (Location) is.

7. feladat – Egy virtuális gép állapotának lekérdezése

A korábban tanult Azure PowerShell parancs segítségével csak a saját virtuális gépedet kérdezd le.

A parancsban paraméterként add meg az erőforráscsoport nevét és a virtuális gép nevét, és kérdezd le a VM aktuális állapotát is.

8. feladat – A virtuális gép leállítása és elindítása

A korábban megismert Azure PowerShell parancsok segítségével:

  1. állítsd le a saját virtuális gépedet az erőforráscsoport és a VM nevének megadásával;
  2. várd meg a leállítás befejezését;
  3. indítsd el újra ugyanazt a virtuális gépet;
  4. ellenőrizd, hogy a VM ismét futó állapotba került-e.

III. Windows PowerShell az Azure VM-en

9. feladat – Kapcsolódás RDP-vel és PowerShell indítása

Az Azure Portalon vagy a korábbi gyakorlaton megismert módon töltsd le a VM RDP-fájlját, majd kapcsolódj a virtuális géphez. Jelentkezz be a VM létrehozásakor megadott helyi rendszergazdai fiókkal.

A virtuális gépen indíts el egy Windows PowerShell ablakot, majd futtasd:

$env:COMPUTERNAME

NoteKét különböző menedzsmentszint

A VS Code-ban használt Get-AzVM az Azure-ban lévő VM-erőforrást kérdezi le. Az RDP-kapcsolat után használt Get-Process, Get-Disk és hasonló parancsok már a virtuális gépen futó Windows operációs rendszert vizsgálják.

10. feladat – Folyamatok és szolgáltatások

A virtuális gép PowerShell ablakában végezd el az alábbi lekérdezéseket. Ebben a feladatban még ne használj pipeline-t (|).

  1. A Get-Process paranccsal kérdezd le az explorer nevű folyamatot a megfelelő paraméter használatával.
  2. A Get-Service paranccsal kérdezd le a Windows Update (wuauserv) szolgáltatást a megfelelő paraméter használatával.

Másold be az alábbi mezőbe a két használt PowerShell-parancsot.

11. feladat – CPU, memória és háttértár

Az előadáson a fizikai és virtuális erőforrások kapcsolatát vizsgáltuk. Most nézd meg, milyen erőforrásokat lát a Windows a saját Azure VM-edben. Ebben a feladatban még ne használj pipeline-t (|).

  1. Kérdezd le a processzor adatait a Get-CimInstance segítségével a Win32_Processor osztályból.
  2. Kérdezd le a memória adatait a Get-CimInstance segítségével a Win32_ComputerSystem osztályból.
  3. A Get-Disk paranccsal kérdezd le külön a 0. számú lemezt.
  4. A Get-Volume paranccsal kérdezd le külön a C: meghajtót.

12. feladat – Hálózat és rendszerinformáció

Most kérdezd le a virtuális gép hálózati és rendszerinformációit. Ebben a feladatban még ne használj pipeline-t (|).

  1. A Get-NetIPAddress paranccsal csak az IPv4 címeket kérdezd le a megfelelő paraméter használatával.
  2. A Get-ComputerInfo paranccsal csak a WindowsProductName, WindowsVersion és OsArchitecture tulajdonságokat kérdezd le.

13. feladat – Parancsok összefűzése pipeline-nal

A PowerShellben a | jel segítségével egy parancs kimenetét átadhatjuk a következő parancsnak. Keresd meg az 5 legtöbb working set memóriát használó folyamatot:

Get-Process |
    Sort-Object -Property WS |
    Select-Object -Last 5

Ezután módosítsd a parancsot úgy, hogy a folyamatok csökkenő sorrendben jelenjenek meg, és csak a Name, Id és WS tulajdonságokat lásd.

14. feladat – Változók használata

Tárold el a 0. számú lemez objektumát egy $disk nevű változóban, majd jelenítsd meg a lemez nevét, méretét és állapotát.

$disk = Get-Disk -Number 0
Write-Host "Lemez neve:" $disk.FriendlyName
Write-Host "Lemez mérete:" ($disk.Size / 1GB) "GB"
Write-Host "Állapot:" $disk.OperationalStatus

15. feladat – PowerShell ISE és az első script

A virtuális gépen indítsd el a Windows PowerShell ISE alkalmazást. Válaszd a File → New lehetőséget, és készíts egy system-report.ps1 nevű scriptet.

A script legalább az alábbi információkat jelenítse meg:

  • a számítógép neve;
  • a Windows verziója;
  • a 0. lemez neve és mérete;
  • az 5 legtöbb memóriát használó folyamat neve, azonosítója és memóriahasználata.

Használd fel a korábbi feladatokban megismert parancsokat, pipeline-t és változókat. Mentsd el a scriptet .ps1 kiterjesztéssel, majd futtasd a PowerShell ISE-ben az F5 billentyűvel.

NoteHa a script futtatását a rendszer korlátozza

A PowerShell végrehajtási házirendje (Execution Policy) korlátozhatja a .ps1 fájlok futtatását. Ha ilyen üzenetet kapsz, jelezd az oktatónak; a biztonsági beállításokat ne módosítsd önállóan.

WarningA gyakorlat végén

A feladatok befejezése után állítsd le az Azure virtuális gépedet, és ellenőrizd, hogy Stopped (deallocated) állapotba került. Ezzel elkerülheted a felesleges Azure-erőforrás-felhasználást.
